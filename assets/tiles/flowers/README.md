# 花牌图片放这里

把花牌的 PNG 直接丢进这个文件夹，**文件名随便起**——代码会自动扫描整个文件夹，
每张图当成一种花牌，商店第一排每次随机抽两种摆出来。

## 图片要求

- **比例随意**，竖图就行，现在用的是 **9:12**（比如 1728×2304）。
  代码按图片自己的比例居中贴在牌面上，不拉伸：比牌面瘦的图横向留白，
  比牌面胖的图上下留白。想横向占满就裁成 9:12（牌面本身约 9:13）。
- 四角会自动裁成圆角，半径跟牌身的圆角一样，不用自己在图片上做圆角。
- 图很大也没关系（长边会自动缩到 720 并生成 mipmap），但建议控制在 1000×1500 上下。
- 建议带透明背景的 PNG——这样牌面的象牙底色会透出来，看着像真牌。
- 支持 `.png` / `.webp` / `.jpg`，同名不同格式时优先 png。
- 文件名就是花牌的名字，比如 `春.png`、`梅.png`、`发财花.png`。

## 价格

普通花牌 **10 两**，史诗花牌 **14 两**，都比第二行的道具（6 两）贵。
想改哪张是史诗，就把它加进 `flower_tiles.gd` 的 `EPIC_IDS`；商店里史诗会带标签。

## 效果

效果登记在 `scripts/core/flower_tiles.gd` 的 `EFFECT_KEYS` 里，键是文件名（不带扩展名）：

- **桃花** `combo`（连击）：连续打出刚摸到的牌 → 这张 ×连击数（碰之后的打出会断，杠不会断）
- **荷花** `repeat`（重张）：打出时自己的牌河里已经有同样的牌 → 这张 ×5
- **满天星** `star`（史诗）：每一关额外增加 3 巡

没登记的花牌在商店里显示「效果待定」，买不了。
再做新图的时候，把想要的规则写出来就行（比如「每关多摸一张」「结算银两翻倍」）。
效果代号按「效果」命名、不跟花名绑，所以换图或者加一张同效果的花牌，代码都不用动。

# 视频放这里

主界面（标题那一屏）的循环壁纸视频丢进这个文件夹，**文件名随便起**——
代码会扫这个文件夹，第一段视频就当主界面背景用。

## 格式要求（重要）

**必须是 `.ogv`（Ogg Theora）**，这是 Godot 唯一原生支持的视频格式。
mp4 / mov / webm / gif 丢进来会被当成"无法识别的文件"，不进包、也播不了。

Godot 里能播的视频格式，实测本项目的引擎版本（4.7.2）只认：

```
VideoStream 认识的扩展名：ogv
WebM 支持：没有
```

## 怎么把 mp4 转成 ogv

用 ffmpeg（没装的话：`winget install Gyan.FFmpeg`）：

```powershell
# 720p、去掉音轨（主界面背景一般不需要视频自带的声音）
ffmpeg -i 原视频.mp4 -an -c:v libtheora -q:v 7 -vf "scale=1280:-2" 主界面.ogv

# 想要声音就把 -an 换成 -c:a libvorbis -q:a 4
```

参数怎么调：

- `-q:v 7`：画质，0~10，越大越清楚、文件越大。背景视频 6~7 就够。
- `scale=1280:-2`：宽度压到 1280，高度自动（`-2` 是为了保证是偶数）。
  只铺满背景的话 1280 宽足够，1080p 会让文件大好几倍。
- 15 秒的 720p 背景大概 3~10 MB，1080p 可能到 30 MB 以上。

## 播放表现

- Theora 是**软解**（CPU 解码），不是显卡硬解。背景视频建议别超过 720p，
  否则低配机器上游戏本身会掉帧。
- 循环由代码控制（`VideoStreamPlayer.loop = true`），不用你处理首尾衔接，
  但视频本身的**首尾画面要能接得上**，循环时才不跳。
- 主界面已经有一首 BGM（`assets/audio/bgm/main.mp3`），所以背景视频建议静音，
  免得两条声音打架。

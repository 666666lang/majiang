# 音效目录

```
assets/audio/
├── voice/    牌局结果音：碰、杠、胡了、自摸胡
└── effect/   操作音：摸牌、打出、鼠标悬停在牌上
```

代码会按顺序在 `voice/` 和 `effect/` 里找，**外层主目录也留着**，放在那里的同样能响。
支持 `.wav` / `.ogg` / `.mp3`，同名多种格式时优先 wav。

## voice/

| 文件名 | 英文名（备选） | 什么时候响 |
|---|---|---|
| `碰` | `pong` | 碰 |
| `杠` | `kong` | 杠（明杠、暗杠都用这个） |
| `胡了` | `win` | 荣和（胡别人打出的牌） |
| `自摸胡` | `tsumo` | 自摸胡、杠上开花 |

## effect/

| 文件名 | 英文名（备选） | 什么时候响 |
|---|---|---|
| `fumble` | `摸牌` | 玩家摸牌（含杠后的补摸） |
| `drop` | `打出` | 玩家打出一张牌 |
| `impact` | `悬停` | 鼠标移到自己的手牌上 |

## 注意

- 短音效用 **wav**（44.1kHz、单声道）最干净；mp3 在短促的打击音上会有编码瑕疵。
- 音量统一在 `scripts/audio/sfx.gd` 的 `VOLUME_DB` 调，默认 -4 dB。
- 无头运行（跑测试）时自动静音，不会建音频对象。
